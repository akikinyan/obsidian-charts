# Types

Charts provides a variety of different Charts.

- [Bar Chart](Bar)
- [Line Chart](Line)
- [Radar Chart](Radar)
- [Doughnut Chart](Doughnut)
- [Pie Chart](Doughnut)
- [Polar Area Chart](Polar%20Area)
- [Sankey Chart](Sankey)

This fork also bundles six extra chart types from separate Chart.js
community plugins, not available in upstream `obsidian-charts`:

- [Matrix (Heatmap) Chart](Extra%20Chart%20Types#matrix)
- [Treemap Chart](Extra%20Chart%20Types#treemap)
- [Word Cloud Chart](Extra%20Chart%20Types#word-cloud)
- [Box Plot Chart](Extra%20Chart%20Types#box-plot)
- [Bar with Error Bars Chart](Extra%20Chart%20Types#bar-with-error-bars)
- [Venn Diagram Chart](Extra%20Chart%20Types#venn-diagram)

For more advanced configuration of all Charts, look at [Modifiers](/Modifiers);
